# Native Omarchy controls

The user is choosing a personal photo at their usual desktop, with their current light or dark theme and keyboard workflow. The interface follows that theme rather than introducing its own palette.

Use Omarchy's built-in photo picker, Appearance menu, input prompts, and bar icon button. Restrained color strategy: inherited foreground, background, and accent tokens. System fonts and standard menu spacing. No decorative animation. The bar icon is optional; all actions remain in the menu. Labels are short verbs. Show Pause or Resume according to state. All dynamic QML text uses plain text; never display photo filenames through rich-text tooltips.
